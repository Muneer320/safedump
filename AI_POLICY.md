# AI Policy

## Our Use of AI

This project uses AI systems extensively in its development, including but not limited to:

- Code generation and refactoring
- Architecture and design decisions
- Code review and analysis
- Documentation writing
- Issue triage and response

AI acts as a collaborative tool, not an autonomous decision-maker. Every AI-generated contribution is reviewed, tested, and approved by a human maintainer before being merged.

## Contributor Use of AI

We welcome contributions regardless of how they were created, as long as they meet our quality standards. You may use AI tools to assist in your contributions.

### Rules

1. **You are responsible for your contribution.** Regardless of whether it was written by a human, an AI, or a combination, you are the author and take responsibility for its correctness, license compatibility, and adherence to project standards.

2. **License compliance.** Do not submit AI-generated code if you cannot verify its license. Some AI models may produce code derived from GPL or other copyleft sources. If you did not write the code yourself and cannot verify its origin, do not submit it.

3. **Quality standards.** AI-generated code must meet the same standards as human-written code. It must pass tests, follow the project's coding conventions, and be thoroughly reviewed. The default position is that AI-generated code receives extra scrutiny, not less.

4. **Transparency.** If you used AI assistance in a substantial way (e.g., generating entire functions or files), mention it in your pull request description. This helps reviewers understand what they are reviewing. Casual use of autocomplete or linting tools does not need to be disclosed.

5. **No mass-generated submissions.** Do not use AI to produce large volumes of low-quality contributions (e.g., automated typo fixes, mass refactoring without context). These waste maintainer time and will be rejected.

## Why This Policy

AI is a tool. Like any tool, it can be used well or poorly. This policy exists to ensure that AI assistance does not compromise code quality, license compliance, or the maintainability of the project. It is not intended to discourage AI use but to establish clear expectations.

## Changes

This policy may be updated as AI tools and practices evolve. Contributors will be notified of significant changes via the project's discussion board.
